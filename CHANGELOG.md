# Changelog

## 1.0.0

First public release.

- Floating prompt bar with global shortcut, opens at the mouse
- Gemini image models (Nano Banana, Nano Banana Pro, newer), model list loaded from the API key
- Several variants per click in parallel, browse with thumbnails or Alt+arrow keys, Keep / Discard
- Results placed as masked layers on top, using only commands PhotoCraft allows in bridge mode
- Starts PhotoCraft with the control interface and exchange folder enabled
- Unit tests and an end-to-end test against a mock PhotoCraft
